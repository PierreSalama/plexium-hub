What this app is

Plexium Hub is a companion app for a media server you run yourself. It browses your own library, plays it on your phone, downloads it for offline, and picks up where you left off on another device.

It requires a Plexium Hub server. It is not a streaming service and provides no content of its own. Without a server to connect to, the app has nothing to show you — which is why there is a built-in demo (see below) for anyone who wants to look around first.

Getting started

Trying it without a server
On the first screen, tap Try the demo. It runs entirely from sample content bundled inside the app — no account, no server, and no network connection of any kind.
Connecting to your own server
On the first screen, enter the address of your Plexium Hub server, including https://. The address must be https: iOS blocks plaintext connections outright, and a plain http address simply looks like a server that is down.
Offline downloads
Anything you download stays on the device and plays with no signal. Downloads survive closing the app. If a download seems to be missing after an app update, open it once while online — iOS changes the app's storage location on every update, and the app re-finds its files on the next launch.

Common problems

"Could not connect"
Almost always the server, not the app. Check the server is running and that the address is reachable from outside your home network. On the same Wi-Fi, the app can also reach the server directly by its local address — allow the local network prompt when iOS asks.
Playback stalls or will not start
Try a different title. If only one file fails, that file needs converting on the server; if everything fails, the connection is the problem.
Signed out unexpectedly
Sign in again from Settings. Sessions are held on your own server.
